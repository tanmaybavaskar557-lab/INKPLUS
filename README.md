# INK+ (INK Plus) — Interactive Digital Whiteboard

**Developed by Tanmay Bavaskar**

**INK+** is a fast, lightweight digital whiteboard built specifically for educators, teachers, and students. Inspired by classroom smartboard tools like Note 3, it combines smooth 4K ink rendering with practical teaching utilities in a simple, low-bug desktop experience.

---

### Key Features
* **Smooth 4K Ink Engine:** Low-latency, crisp handwriting and drawing optimized for digital smartboards, pen tablets, and laptops.
* **Built-in Precision Geometry Tools:** Interactive on-screen **Ruler**, **Two-Pointer Compass**, and **Protractor** for teaching Mathematics and Science diagrams effortlessly.
* **Smart Palm-Rejection Erasing:** Natural, hassle-free erasing designed for smooth classroom flow.
* **Multi-Page Slide Management:** Create, organize, and switch between multiple teaching slides during a lecture without losing your notes.
* **Floating Desktop Overlay Ball:** Quick-access floating toolbar to annotate directly over PDFs, presentations, or any desktop screen.
* **Note 3 Inspired Pro Features:** Essential smartboard tools packed into a clean, easy-to-use interface without heavy lag or bloat.

---

### Installation (Windows)
1. Go to the **[Releases](../../releases)** section on the right side of this page.
2. Download the latest **`INK-Plus-Setup.exe`** installer.
3. Run the setup file to install and launch **INK+**.
